# Frozen API contract snapshot (2026-07-27)

Machine-readable capture of the TypeScript monolith's external HTTP contract,
taken at the freeze point of the .NET rewrite
(`docs/plans/2026-07-27-001-feat-dotnet-blazor-rewrite-plan.md`, unit U1).

## Files

| File | Contents |
| --- | --- |
| `2026-07-27-frozen-api-contract.openapi.json` | Full OpenAPI 3 document generated by the running API's Swagger surface (`GET /api-json`), pretty-printed and key-sorted. Includes all request/response schemas (45 component schemas). |
| `2026-07-27-frozen-api-routes.txt` | Flat `METHOD path` inventory extracted from the OpenAPI document — 58 operations. |

## Provenance

- Generated from the API running in the dev container at branch
  `feat/ssr-auth-migration` (the state merged to `development` and tagged as the
  frozen reference spec — see the tag created in U1).
- Source of truth is the NestJS Swagger document (`SwaggerModule.createDocument`
  in `apps/backend/api/src/main.ts` at that tag), so the snapshot and the tagged
  source describe the same code.

## Surface summary

- `/v1/auth/*` — 14 operations (sessions + CSRF, integration tokens, PIN/OTP,
  password + username recovery, onboarding).
- `/v1/user*` — 6 operations (profile, password, staff creation, role change).
- `/v1/settings` — 2 operations (read, update).
- `/v1/templates*` — 7 operations (CRUD, validation, draft render).
- `/v1/coms/*` — 9 operations (email/SMS send, batches, recipients, resends,
  provider webhook).
- `/v1/docs*` — 9 operations (upload, generate, URLs, deletion, bulk delete).
- `/v1/health*` — 2 operations.
- `/fhir/R4/{Patient,Encounter,ServiceRequest}` — 9 operations (FHIR R4,
  version-neutral routes).

The rewrite treats this snapshot as the specification for contract tests
(plan units U12–U16). Rebuild scope for the minor release covers the `/v1`
surface plus patient lookup; FHIR encounter/service-request routes are part of
the clinical follow-up, not the minor.

Note: the plan's prose says "43 routes" (GitNexus route count at planning time);
the authoritative number is this snapshot's 58 method+path operations.
